# Duo 插件管理 (Duo Addon Manager)

现代化、极简暗黑美学的高颜值《魔兽世界》插件管理器。支持 Curse 分类聚类、角色独立方案绑定、跨角色自动改动对齐、实时内存监控与小地图图标收纳坞。

---

## ✨ 核心特色

- **🎨 极简暗黑与动态主题**：内置暗金尊享、职业专属、翡翠森林、深海幽蓝 4 款经由专业暗色 UI 调校的主题配色方案，毫秒级热切换。
- **⚡ 瀑布流双列卡片布局**：分类清晰，支持一键启停、父子插件抽屉折叠、主插件设置面板直达。
- **🔄 方案闭环与角色独立隔离**：
  - 支持多套方案自由切换（大秘境、团本、PVP、野外）。
  - **角色独立存储（Anti-bleed）**：不同角色默认绑定各自方案，换号绝不串方案。
  - **跨角色智能改动检测**：当小号登入发现共享方案在其他角色上有更新时，自动同步并温和提示重载。
  - **实时自动保存**：所有勾选状态即时落盘，无需繁琐的手动点击保存。
- **🔍 智能检索与快捷交互**：
  - 拼音/首字母/中英文双向实时模糊匹配，高亮命中字符。
  - 一键清空按钮 `[✕]` 与 ESC / 回车键智能失焦。
- **🚀 性能级防抖节流引擎**：
  - 内存扫描智能节流，杜绝快速点击与打字微卡顿。
  - 会话级卡片排序快照，操作时卡片绝不在鼠标指针下突兀跳动。
- **📦 极简小地图收纳坞**：
  - 自动收纳杂乱的单体插件小地图图标，保持界面干净清爽。
  - 左键切换图标抽屉，右键打开管理器主界面，右键拖拽自由摆放。

## ⌨️ 常用命令

| 命令 | 说明 |
| :--- | :--- |
| `/am` 或 `/addons` | 打开 / 关闭插件管理器主界面 |
| `/rl` | 快速重载界面 (ReloadUI) |
| `/am gold` / `class` / `emerald` / `royal` | 快捷切换主题配色 |
